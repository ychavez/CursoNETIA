# Material de clases

[Abrir la presentación para alumnos (PowerPoint)](00-presentacion-alumnos.pptx).

Usa la presentación al inicio del curso para mostrar el proyecto y el panorama de las diez clases. Reutiliza la lámina de cada clase al comenzar la sesión para explicar qué aprenderán y qué harán.

Cada módulo incluye una explicación breve de su propósito y contexto, además de los objetivos y la práctica. Las notas del presentador añaden un ejemplo aplicado a AulaPedidos.
